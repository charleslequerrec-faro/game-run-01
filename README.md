# Fast Fox!

Jeu de course en pixel art, jouable au doigt sur mobile. Tout le jeu tient dans `index.html`, sans dépendance.

Pour le mettre en ligne avec GitHub Pages : Settings, Pages, source « Deploy from a branch », branche `main`, dossier `/ (root)`.

La police Pixelify Sans, intégrée au fichier, est sous licence SIL Open Font License 1.1.
